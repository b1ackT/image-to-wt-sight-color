# Image to WT Sight Color

将 PNG、JPG 或 WebP 转成《战争雷霆》陆战彩色装饰瞄具。直接在浏览器打开 `dist/index.html` 即可离线使用。也可以运行 `npm start`，再访问 http://127.0.0.1:4173 。

1. 载入图片。带透明背景的 PNG 通常效果最好。
2. 调整采样精度、透明过滤、尺寸和位置。每个可见采样像素生成一个文字图元。超过预算时，工具会降低整张图的采样精度。
3. 下载彩色 BLK，放进 `文档\My Games\WarThunder\Saves\<用户ID>\production\UserSights\all_tanks\`。如果游戏没有列出文件，可改用对应车辆 ID 的子文件夹。
4. 重启游戏，在“选项 → 陆战设置 → 瞄具设置 → 瞄具准星”中选择并保存。先在试驾里检查颜色和位置，再调文字倍率。字形太疏时提高倍率，重叠时降低倍率。

先用 [四色测试文件](examples/color_probe.blk) 检查红、绿、蓝和半透明黄是否都能显示。还有一份[白色几何对照](examples/quad_geometry_control.blk)，用于排查文件安装和选择问题。

## 彩色格式

彩色导出通过 `drawTexts` 绘制图案。每个文字图元用 `color:c` 设置颜色和透明度，用 `highlight:b=no` 固定颜色。`pos:p2` 和 `size:r` 控制字形的位置和大小。

彩色导出使用 `〓` 字形拼出图案。网页预览使用方形像素，游戏中的字形、放大倍率和间距可能有差异。旋转会调整字形中心的位置，字形本身保持直立。默认文字倍率为 155，最高图元预算为 7,900。实际效果仍待游戏内验证。

单色导出保留 `drawQuads` 填充几何，使用全局颜色。PNG 导出保存透明像素预览。运行 `npm test` 可检查透明度、采样预算、坐标变换和 BLK 字段。
